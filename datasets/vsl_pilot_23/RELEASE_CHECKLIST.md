# VSL Pilot Release Checklist

- [ ] Obtain written consent from the author-signer covering public release of derived pose data.
- [ ] Confirm that no raw videos, images, filenames, EXIF data, or personal metadata are included.
- [ ] Confirm institutional policy or ethics review status for this self-recorded pilot.
- [ ] Review `metadata.json` and `SHA256SUMS` before publication.
- [ ] Publish only after the checklist is complete.

The release contains derived pose features only. This does not by itself make
the data anonymous or remove all biometric sensitivity.
